# /brainstorm

Invoke the **brainstorming** skill to explore ideas before coding.

## Usage

```
/brainstorm <topic or feature description>
```

## What Happens

1. The brainstorming skill activates
2. You frame the problem, list constraints, generate 2-3 options
3. A design spec is saved to `docs/specs/`
4. The spec can be used as input for the **writing-plans** skill

## Example

```
/brainstorm Add a document upload feature with drag-and-drop
```
